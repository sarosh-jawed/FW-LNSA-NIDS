These aggregate proofs are preserved byte-for-byte from the completed Work provenance audit, separately from the later Colab experiment. They contain column-level mismatch counts, candidate mirror identities and selected-projection equivalence, with no network-record rows or personal paths.

The candidate mirrors agree with one another but differ from the accepted binary file at 306 service values. All other predictors and binary labels align. Both primary selected projections are identical. The strict raw-feature alignment gate fails, so named attack families remain unavailable.

`scripts/audit_nsl_canonical_alignment.py` implements the original strict audit. Rechecking it requires the original training/binary-test bytes and the pinned candidate mirrors identified in the JSON. This check does not fit new detectors or alter any accepted source. The private manuscript handoff preserves the original audit context and manifests.
